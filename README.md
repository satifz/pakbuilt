# OVERALL DESIGN DIRECTION

Create a website that looks like a **modern construction-supply and solutions company**, NOT a generic hardware store.

The design should be:

* Modern
* Premium
* Clean
* Bold
* Professional
* Industrial
* Trustworthy
* Fast
* Easy to navigate
* Visually memorable

Use a strong **orange + dark charcoal/black + white/light neutral** visual system.

Orange should be the primary accent colour and should be used strategically for:

* CTA buttons
* highlights
* icons
* small design elements
* hover states
* important headings/accents

Do not make the entire website orange.

Use large, high-quality construction / architecture / materials imagery.

Avoid cliché stock imagery wherever possible.

Use generous whitespace, strong typography, subtle shadows, clean cards and modern grid layouts.

The finished website should feel like:

**Construction industry + modern procurement company + professional B2B brand + Pakistani personality.**

* a generic WordPress construction template
