# Add Shopify-Powered Shop to PakBuilt

Connect the newly created (and claimed) Shopify store to the website and add a premium shop experience, using the existing navy/red PakBuilt design language. No redesign of existing pages.

## What gets built

1. **Shopify connection layer**
   - `src/lib/shopify.ts`: Storefront API helper (`storefrontApiRequest`), constants resolved from the integration (permanent domain, storefront token, API version 2026-10), product GraphQL types and query.
   - Products are always loaded live from Shopify — prices, images, availability and stock reflect what is managed in Shopify admin. No mock products anywhere.

2. **Cart system (real Shopify cart)**
   - Install `zustand`; `src/stores/cartStore.ts` with persistent cart state (localStorage) and real-time sync with Shopify via `cartCreate` / `cartLinesAdd` / `cartLinesUpdate` / `cartLinesRemove`, line-ID tracking, and "cart not found" recovery.
   - `src/hooks/useCartSync.ts` mounted in `src/routes/__root.tsx` so returning from checkout clears the cart.
   - `CartDrawer` sliding panel: items, quantities, remove, total, and a "Checkout" button that opens the Shopify-hosted checkout in a new tab (URL always generated by the Storefront API with `channel=online_store`; never manual URLs).

3. **Shop page `/shop`**
   - Premium hero + product grid in PakBuilt style: image, title, price, description from Shopify, "Add to Cart" buttons, cards link to product detail pages.
   - Search + category filter chips (Shopify search query), loading skeletons, empty state ("No products found") when the store has no products.
   - Own title/description/OG/canonical metadata, Breadcrumbs, Service-free Product-ready markup, sitemap entry in `public/sitemap.xml`.

4. **Product detail pages `/product/$handle`**
   - Same info as the card plus all images, options/variant selection, availability, quantity, Add to Cart. Generated metadata (title/description/og:image from product data).

5. **Navigation & footer**
   - Add "Shop" to `navLinks` in `src/data/company.ts` (desktop + mobile menu) and a cart icon with item-count badge in the header.

## Constraints
- Keep all existing pages, sections, branding, fonts, and functionality untouched except the header/footer additions above.
- No fabricated reviews/ratings; no fake products; if the store is empty the page shows the empty state and I will ask you what products to create.
- Store currency follows the store's configured currency (PKR) — no cross-currency display.

## Verification
- TypeScript check; Playwright run on `/shop` and a product page: product data loads from Shopify, add-to-cart updates the drawer badge, quantity change/remove works, checkout URL includes `channel=online_store`, no console errors, no overflow on mobile.
- Product-count check against the store; if zero products, report and ask you for product names + prices to create them.

## Notes
- You manage products, stock, and orders in your Shopify admin (linked in the Shopify menu); the website mirrors that data automatically.
